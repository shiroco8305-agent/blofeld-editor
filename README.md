# Blofeld Editor

Single-file Web MIDI SysEx editor for the Waldorf Blofeld (Sound mode, SysEx spec v1.04): oscillators, filters, envelopes, LFOs, effects, arpeggiator, modifiers and the 16-slot modulation matrix. Parameter edits are sent live as SNDP messages; the edit buffer can be requested (SNDR) and sent/saved as an SNDD .syx dump.

**Open:** https://shiroco8305-agent.github.io/blofeld-editor/

- Needs Chrome or Edge on desktop or Android (Web MIDI + SysEx). iPad/iPhone browsers have no Web MIDI.
